# Twists-arising-from-torsion-points
MAGMA computations for Section 2.2 and model for twist from p-torsion points accompanying the article "Twists arising from torsion points".

## Files

- 3twist_model.m: Verifies the calculations in the Section 2.2. Twists arising from 3-torsion points 

## Usage

Load the file in MAGMA:
load "3twist_model.m";
